Privacy Policy

Last updated: October 21, 2026

IUH Calendar Sync is a personal desktop application designed to synchronize class schedules from the Industrial University of Ho Chi Minh City (IUH) student portal with Google Calendar.

1. Information We Access

The application may access the following information:

  • University timetable information, including course names, class dates, times, locations, and instructor names.
  • Google Calendar event information necessary to create or update class schedule events.
  • Google OAuth authorization credentials required to access Google Calendar with user permission.

2. How Information Is Used

The application uses this information exclusively to synchronize university timetable data with the user's selected Google Calendar.

Google Calendar permissions are used to create and update timetable events and perform related synchronization operations.

3. Data Storage

IUH Calendar Sync runs locally on the user's computer.

Timetable data and application configuration may be stored in local files. Google OAuth credentials, including authorization tokens, may also be stored locally to enable future synchronization.

Calendar event information is transmitted to Google Calendar through Google's authorized API when synchronization is requested.

4. Data Sharing

The application does not sell personal data or use Google user data for advertising.

Information is shared with Google services only as needed to perform the requested Google Calendar synchronization.

5. Google API Services

IUH Calendar Sync uses Google API Services. Its use of information received from Google APIs will adhere to the Google API Services User Data Policy , including the Limited Use requirements.

6. Data Security

The application uses Google OAuth 2.0 for authorization and does not require the user to provide a Google account password directly to the application.

Users are responsible for protecting their local computer, application configuration files, and locally stored authorization tokens.

7. Revoking Access and Deleting Data

Users may revoke the application's access to their Google Account at any time through Google Account settings.

Users may also delete locally stored timetable files and authorization tokens from their computer.

Revoking access prevents future synchronization until the user grants permission again. Existing Google Calendar events may remain until the user removes them.

8. Policy Updates

This Privacy Policy may be updated when the application's functionality or data handling practices change.

9. Contact

For questions about this Privacy Policy, please contact the application developer through the project's public GitHub repository:

IUH Calendar Sync is an independent personal educational project and is not officially affiliated with Google or IUH.
