IUH Calendar Sync

IUH Calendar Sync is a personal desktop application that synchronizes university class schedules with Google Calendar.

About the Application

IUH Calendar Sync helps its user organize class schedules by retrieving timetable information from the IUH student portal and creating or updating corresponding events in Google Calendar.

Main Features

  • Retrieve university timetable information.
  • Create and update Google Calendar events.
  • Support manual and scheduled synchronization.
  • Run locally on the user's computer.

Google Calendar Integration

The application requests Google Calendar access only after the user grants permission through Google OAuth 2.0.

Google Calendar data is used only to perform timetable synchronization. The application is not an official product of Google or Industrial University of Ho Chi Minh City.
